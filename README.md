Tarea CRUD MVC Web
Descripción

Aplicación web desarrollada utilizando la arquitectura Modelo-Vista-Controlador (MVC), con una interfaz diseñada mediante Bootstrap.

El proyecto permite realizar el registro y visualización de información mediante los módulos implementados.

Módulos
Clientes
Empleados

Cada módulo cuenta con su respectivo modelo, controlador y vista, siguiendo la estructura de la arquitectura MVC.

Java
Spring Boot
MVC (Modelo-Vista-Controlador)
Thymeleaf
Bootstrap
MySQL
Maven
